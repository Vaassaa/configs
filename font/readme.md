# Hermit font

## Find it

```
pacman -Ss hermit
```

## Install it

```
sudo pacman -S otf-hermit-nerd
```

## Update the font cache

```
fc-cache -f
```

## Set it in Konsole

Settings → Edit Current Profile… → Appearance → Font → Choose…

Pick **Hurmit Nerd Font Mono**. The font is listed as "Hurmit", not "Hermit".
